## 01 / WHOAMI

I work at the intersection of **offensive security research** and **application security engineering** — assessing web, API, mobile, and cloud systems to identify how they actually break, not just how they're documented to work.

My approach is deliberately methodical: map the attack surface, understand trust boundaries and data flow, validate assumptions through hands-on testing, and translate findings into evidence-backed, remediation-ready reporting. I spend equal time on client-facing **VAPT engagements** and independent **security research**, and I treat both with the same rigor — reproducible proof-of-concept over speculation, and impact framed in terms an engineering team can act on.

Currently building depth across offensive security fundamentals, AWS cloud security, and detection engineering — with security engineering, not just security testing, as the long-term direction.
